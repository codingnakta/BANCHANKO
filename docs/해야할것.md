## 2. 아직 안 만든 화면·기능

  적어 두었으므로 만들어야 한다. 교사가 탈퇴하면 학급 전체가 지워지는 처리까지 필요.

- [ ] **출결 기록 들어가는 길** — 화면(`/teacher/attendance`)은 있는데 메뉴에서 뺐다.
  지금은 챗봇에게 "출결 기록하고 싶어"라고 해야만 들어간다. 우리반 목록에 줄을
  하나 넣을지 정해야 한다.

- [ ] **학생이 자기 출결 보기** — 처리방침 제13조 6항에 "학생은 본인 출결 상태를
  화면에서 확인할 수 있다"고 적었는데 그 화면이 없다.

- [ ] **공지 열람 기록(읽음)** — `Notice.isRead` 가 항상 false 다. 처리방침 제2조에
  수집 항목으로 적어 두었다. 알림 읽음(`notification_reads`)과 합칠 수 있다.

- [ ] **챗봇 대화 기록 저장** — 지금은 화면을 나가면 사라진다. 처리방침 제10조 5항에
  "6개월 보관 후 파기"라고 적어 두었으므로 테이블이 필요하다.

- [ ] **학년도 종료 시 일괄 삭제** — 약관 제21조·처리방침 제4조의 핵심 약속인데
  지우는 방법이 없다. 학년도 종료일과 삭제 버튼(또는 정기 작업)이 필요하다.

  둘뿐이다. 안 쓸 거면 타입에서 빼는 편이 낫다.

- [ ] **현재 교시 강조** — `currentPeriod` 를 아무도 채우지 않아 시간표에서 지금
