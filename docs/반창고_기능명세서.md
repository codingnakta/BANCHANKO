### 전역 제약 (모든 기능 공통)
- 학생은 자신의 소속 학급 데이터만 조회할 수 있다. 타 학급·타 학생의 민감 정보(출결 사유 등)에 접근할 수 없다.
- 담임교사는 자신의 학급 1개만 생성·관리한다. 학생은 동시에 1개 학급에만 소속된다.

- 서비스 내부 파일 업로드·다운로드, 학생 파일 제출, 학생별 제출 현황 관리는 제공하지 않는다. (외부 자료 URL 연결만 허용)
- 초기 버전 알림은 인앱 알림만 제공한다. (푸시·문자·이메일 없음)

# 1. 요구사항 정의 (Requirements)

## R-VKJVSP 역할 기반 계정 및 학급 소속 관리 `high`
서비스는 이메일 로그인 기반으로 담임교사, 학생, 서비스 관리자 역할을 구분하고 역할별 이용 범위를 제한해야 한다. 담임교사는 하나의 학급만 생성·관리하고 학생은 하나의 학급에만 소속되며, 승인된 담임교사만 학급 운영을 시작할 수 있다. 다른 학급의 정보나 다른 학생의 민감 정보 접근은 이 요구사항 범위에서 차단한다.

**수락 기준**
- [ ] 이메일 로그인 후 사용자 역할에 따라 담임교사·학생·서비스 관리자용 접근 범위가 다르게 적용된다.
- [ ] 서비스 관리자가 승인하지 않은 담임교사 계정은 학급을 생성하거나 운영할 수 없다.
- [ ] 담임교사는 한 개의 학급만 생성할 수 있고, 학생은 한 개의 학급에만 소속될 수 있다.
- [ ] 학생은 자신의 소속 학급 데이터만 조회할 수 있으며 다른 학생의 출결 사유 등 민감 정보를 볼 수 없다.

하위 기능: F-UBHBGS

## R-XQCNMO 학급 기본 정보 및 학생 초대 관리 `high`
담임교사는 학급 공간을 만들고 학생을 초대하거나 등록하며, 학급 규칙·시간표·청소 당번 등 반복적으로 사용하는 학급 기본 정보를 설정할 수 있어야 한다. 학생 소속의 추가·변경·해제는 권한 있는 담임교사가 관리한다. 이 요구사항은 공지나 과제 같은 개별 안내 콘텐츠의 작성 기능은 포함하지 않는다.

**수락 기준**
- [ ] 담임교사는 학급명과 기본 학급 정보를 입력하여 자신의 학급 공간을 생성할 수 있다.
- [ ] 담임교사는 학생을 초대 또는 등록하고 학급 소속 학생 목록을 확인할 수 있다.
- [ ] 담임교사는 학생의 학급 소속을 해제할 수 있으며, 해제된 학생은 해당 학급의 신규 정보에 접근할 수 없다.
- [ ] 담임교사는 학급 규칙, 주간 시간표, 청소 당번을 등록·수정할 수 있다.

하위 기능: F-RONORQ, F-FMLMIG

## R-TUTZNW 공지·가정통신문·과제 일정 관리 `high`
담임교사는 공지사항, 가정통신문, 과제 일정을 학급 구성원에게 전달할 수 있어야 한다. 각 안내에는 대상, 공개일, 마감일 및 필요한 경우 외부 자료 URL을 설정하며, 학생은 공개된 자신의 학급 안내만 확인한다. 서비스 내부 파일 업로드·다운로드, 학생 과제 파일 제출 및 학생별 제출 현황 관리는 제공 범위에서 제외한다.

**수락 기준**
- [ ] 담임교사는 공지사항·가정통신문·과제 일정을 작성, 수정, 공개 및 종료할 수 있다.
- [ ] 교사는 안내별 대상, 공개일, 마감일과 외부 자료 URL을 설정할 수 있다.
- [ ] 학생은 공개 시점 이후 자신에게 해당하는 공지·가정통신문·과제 일정만 조회할 수 있다.
- [ ] 과제 안내 화면에는 서비스 내부 파일 제출 또는 학생별 제출 현황 관리 기능이 제공되지 않는다.

하위 기능: F-WSHIYO

## R-NADQZB 학생용 오늘의 학급 정보 대시보드 `high`
학생은 로그인 후 오늘의 학급생활에 필요한 정보를 한 화면에서 우선순위에 따라 확인할 수 있어야 한다. 화면은 오늘 시간표, 급식, 청소 당번, 미확인 공지, 예정된 과제 및 학급 행사를 통합하여 보여준다. 상세 원본 정보의 수정은 학생이 아닌 담임교사에게만 허용한다.

**수락 기준**
- [ ] 학생 첫 화면에서 오늘 시간표, 급식, 청소 당번, 미확인 공지, 예정 과제 및 학급 행사를 확인할 수 있다.
- [ ] 각 요약 항목에서 해당 공지, 과제, 일정 등 상세 정보로 이동할 수 있다.
- [ ] 마감일이 임박했거나 당일인 과제와 행사는 일반 예정 정보와 구분되어 표시된다.
- [ ] 학생은 대시보드에서 학급의 시간표·급식·청소 당번·일정 원본 데이터를 수정할 수 없다.

하위 기능: F-ZTJSNU

## R-CZXHBJ 학급 일정과 외부 연동 정보의 검수·공개 `high`
담임교사는 학급 행사와 일정을 직접 관리하고, 나이스 API에서 수집한 시간표·급식 등 외부 정보를 검토한 후 학생에게 공개할 수 있어야 한다. 자동 연동 데이터는 교사 검수 없이 학생에게 자동 공개되지 않으며, 오류나 변경 사항은 교사가 수정할 수 있다. API 장애 시에도 학급 운영이 중단되지 않도록 수동 입력과 마지막 정상 데이터를 지원한다.

**수락 기준**
- [ ] 담임교사는 학급 행사와 일정을 등록·수정·삭제하고 학생 공개 여부를 관리할 수 있다.
- [ ] 외부 API에서 가져온 시간표 또는 급식 정보는 검수 대기 상태로 표시되며, 교사가 공개하기 전에는 학생에게 노출되지 않는다.
- [ ] 담임교사는 연동된 시간표와 급식 정보를 수정한 뒤 학생에게 공개할 수 있다.
- [ ] 외부 API 연동 실패 시 담임교사는 정보를 수동 입력할 수 있고, 마지막 정상 데이터에는 기준 시각이 표시된다.

하위 기능: F-WFEXUJ, F-OHHQTM

## R-KPYPXS 출결 기록 및 변경 이력 관리 `high`
담임교사는 학급 학생의 출결 상태와 사유를 기록하고 정정할 수 있어야 하며, 변경 이력을 확인할 수 있어야 한다. 출결 기능은 학교의 공식 행정 시스템을 대체하지 않고 담임교사의 기록·조회 보조 용도로만 제공한다. 학생은 본인 관련 출결 안내 외 다른 학생의 출결 상태나 사유에 접근할 수 없다.

**수락 기준**
- [ ] 담임교사는 소속 학생별 출결 상태와 출결 사유를 기록하고 수정할 수 있다.
- [ ] 출결 정보가 수정되면 수정 시각, 수정자 및 변경 전후 내용이 이력으로 남는다.
- [ ] 담임교사는 자신의 학급 학생 출결 기록과 변경 이력을 조회할 수 있다.
- [ ] 학생은 다른 학생의 출결 상태나 출결 사유를 조회할 수 없다.

하위 기능: F-ZOJYKF

## R-TSCMXY 학급 데이터 근거 AI 챗봇 `high`
학생은 자연어로 학급 일정, 과제, 공지, 급식, 청소 당번 및 행사 정보를 질문하고 AI 챗봇의 답변을 받을 수 있어야 한다. AI는 학생이 접근 가능한 저장된 학급 데이터만 근거로 답변하며, 답변의 근거와 최종 갱신 시각을 함께 제공한다. 학급 데이터 밖의 질문, 근거가 부족한 질문, 권한이 없는 정보에 대해서는 답변 범위를 명확히 제한한다.

**수락 기준**
- [ ] 학생은 '오늘 과제', '내일 청소 당번', '이번 주 행사와 준비물'과 같은 자연어 질문을 입력할 수 있다.
- [ ] AI 답변은 질문 학생의 소속 학급 및 접근 권한이 있는 데이터만 사용한다.
- [ ] AI 답변에는 참조한 학급 정보의 출처와 최종 갱신 시각이 표시된다.
- [ ] 근거 데이터가 없거나 권한 밖의 질문인 경우 AI는 추정 답변 대신 답변 가능 범위 또는 확인이 필요함을 안내한다.

하위 기능: F-CCZIQT

## R-XEYDGF AI 기반 안내 요약 및 오늘 할 일 생성 `medium`
담임교사와 학생이 긴 안내와 흩어진 일정을 빠르게 이해할 수 있도록, AI는 저장된 학급 데이터를 바탕으로 공지 요약과 학생용 오늘의 할 일을 생성해야 한다. 생성 결과는 원본 공지와 일정에 연결되어 검토 가능해야 하며, 사실을 임의로 추가해서는 안 된다. 이 요구사항은 교사가 작성한 원본 안내를 자동으로 변경하는 기능을 포함하지 않는다.

**수락 기준**
- [ ] 공지 또는 가정통신문 상세 화면에서 저장된 원문을 기반으로 한 요약 내용을 확인할 수 있다.
- [ ] 학생 대시보드에서 당일 및 임박한 학급 데이터에 기반한 오늘의 할 일을 확인할 수 있다.
- [ ] AI 생성 요약과 할 일에서 관련 원본 공지·과제·일정으로 이동할 수 있다.
- [ ] 생성 결과에 근거가 되는 학급 데이터가 없을 경우 임의의 준비물, 일정 또는 과제를 추가하지 않는다.

하위 기능: F-NXPULH

## R-MVXQOC 인앱 알림 및 확인 상태 `medium`
서비스는 새로운 공지, 임박한 과제 일정, 청소 당번, 학급 행사 등 학생의 확인이 필요한 학급 변경 사항을 인앱 알림으로 제공해야 한다. 학생은 알림 목록과 읽음 여부를 확인하고 관련 정보로 이동할 수 있다. 초기 출시 범위에서는 모바일 푸시, 문자 및 이메일 알림을 포함하지 않는다.

**수락 기준**
- [ ] 학생에게 새 공지, 임박한 과제, 청소 당번 또는 학급 행사 관련 인앱 알림이 표시된다.
- [ ] 학생은 알림 목록에서 읽음·읽지 않음 상태를 구분하여 확인할 수 있다.
- [ ] 알림을 선택하면 연결된 공지, 과제, 일정 또는 당번 정보로 이동한다.
- [ ] 초기 버전에서는 모바일 푸시, 문자, 이메일 발송 기능이 제공되지 않는다.

하위 기능: F-IAXPMY

## R-WWNRPM 개인정보 보호, 계정 종료 및 보관 정책 `high`
서비스는 학생 정보와 출결 정보를 최소 수집하고 역할 기반 접근 제어 및 감사 가능한 처리 이력을 통해 보호해야 한다. 계정 탈퇴 또는 비활성화 시 로그인은 즉시 차단하며, 정해진 보관 기간 이후 식별 정보를 삭제하거나 익명 처리한다. 이 요구사항은 학급 운영 정보의 일반 조회 기능이 아니라 개인정보의 접근·삭제·보관 통제를 다룬다.

**수락 기준**
- [ ] 계정 탈퇴 또는 비활성화된 사용자는 즉시 로그인하거나 신규 학급 데이터에 접근할 수 없다.
- [ ] 탈퇴·비활성화 후 30일의 철회 가능 기간이 지나면 계정 식별 정보가 삭제된다.
- [ ] 학급 종료 또는 학생 탈퇴 후 출결 사유는 해당 학년도 종료일로부터 1년 후 삭제 또는 익명 처리된다.
- [ ] AI 질문·오류 신고·알림 기록은 생성일로부터 90일 후 식별 정보가 삭제되며, 삭제·익명 처리 이력은 1년간 감사 목적으로 보관된다.

## R-OSTJMD 전역 탐색과 화면 구조 `high`

| 데이터 | 계정 종료 정보는 계정 상태, 종료 요청 시각 및 식별 정보 삭제 예정 시각을 가진다. 감사 이력은 처리 유형, 대상 식별자, 처리 시각 및 처리자를 가진다. |

## F-ZYSPUS 하단 탭바 탐색
- 소속 요구사항: R-OSTJMD · 중요도: high · 역할: 담임교사, 학생

**정의**: 로그인한 학생과 담임교사는 모든 주요 화면 하단의 탭바로 홈, 우리반, 할일, 더보기 화면을 이동한다. 홈은 오늘 필요한 학급 정보의 요약과 우선 항목을, 우리반은 구성원·규칙·시간표·급식·청소 당번 등 학급 운영 정보를, 할일은 마감 임박 과제 일정·미확인 공지·다가오는 행사와 AI가 생성한 오늘 할 일을 제공한다. 더보기는 알림 목록, 계정과 개인정보 관리, 서비스 안내를 제공하며 각 탭은 해당 화면의 상세 관리 기능을 대체하지 않는다.

**존재 이유**: 학생과 담임교사가 흩어진 학급 정보와 개인 메뉴에 빠르게 접근하고, 화면마다 이동 경로를 새로 학습하지 않도록 해야 한다.

| 슬롯 | 내용 |
|---|---|
| 선행조건 | 사용자가 로그인한 상태여야 한다. |
| 트리거 | 사용자가 하단 탭바의 홈, 우리반, 할일 또는 더보기 탭을 선택한다. |
| 동작 | 시스템은 선택한 탭에 해당하는 화면으로 이동한다. 시스템은 현재 화면에 해당하는 탭을 선택 상태로 표시한다. 시스템은 탭 이동 시 사용자의 역할과 학급 소속에 따라 조회 가능한 정보만 표시한다. |
| 결과 | 사용자는 홈, 우리반, 할일, 더보기의 네 가지 최상위 화면을 일관된 경로로 이동한다. 시스템은 탭 선택과 각 탭 화면 진입 이벤트를 기록한다. |
| 예외 | 선택한 탭의 일부 데이터를 불러오지 못하면 이동은 유지하고 해당 영역에 다시 시도 안내를 표시한다. 사용자가 현재 선택된 탭을 다시 선택하면 화면 위치와 상태를 유지한다. |
| 표시 | 하단 탭바는 홈, 우리반, 할일, 더보기의 이름과 아이콘을 함께 표시한다. 현재 선택된 탭은 다른 탭과 시각적으로 구분해 표시한다. 홈 탭은 오늘 시간표, 급식, 청소 당번, 미확인 공지, 예정 과제와 행사의 요약 및 우선 항목을 표시한다. 우리반 탭은 학생에게 학급 규칙, 시간표, 급식, 청소 당번, 공지·과제·행사 목록을 표시한다. 우리반 탭은 담임교사에게 학생 관리, 학급 기본 정보, 공지·과제·행사 관리, 시간표·급식 검수와 출결 기록으로 이동하는 메뉴를 표시한다. 할일 탭은 마감 임박 과제 일정, 미확인 공지, 다가오는 행사와 AI가 생성한 오늘 할 일을 원본 이동 경로와 함께 표시한다. 더보기 탭은 알림 목록, 계정과 개인정보 관리, 서비스 안내 메뉴를 표시한다. |
| 권한·접근 | 학생과 담임교사는 네 개의 탭에 접근할 수 있다. 우리반과 더보기 화면의 메뉴는 사용자 역할에 따라 다르게 표시한다. 학생에게 출결 기록 관리와 학생 소속 관리 메뉴를 표시하지 않는다. |
| 규칙 | 하단 탭바는 로그인 후 주요 화면에서 지속적으로 표시한다. 원본 상세 화면이나 작성·수정 화면에서는 하단 탭바를 표시하지 않는다. 탭은 홈, 우리반, 할일, 더보기 순서로 고정한다. 더보기 탭에는 알림 확인, 계정과 개인정보 관리, 서비스 안내만 포함하고 학급 운영 기능은 포함하지 않는다. |
| 데이터 | 하단 탭바는 별도의 사용자 입력 데이터를 저장하지 않는다. 시스템은 탭별 진입 이벤트에 사용자 역할, 탭 이름 및 발생 시각을 기록한다. |

**성공 지표**: 탭별 화면 진입률과 주요 화면 탐색 완료율을 측정한다.
